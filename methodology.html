METHODOLOGY

資料方法與更正原則

候選人文化政見

收錄候選人本人、競選團隊、政黨正式平台或可信媒體可追溯來源中，具有政策目標、執行方式、資源配置或制度主張的文化政見。單純參訪藝文活動、與藝文人士合照、個人經歷或價值宣示，不視為政見。

來源與查核

每筆資料保存原始來源網址、發布日期、最後查核日與更正紀錄。來源失效時保留紀錄並另尋存檔或交叉來源，不逕行刪除。

地方文化財政

「文化預算」採機關別分類，主要指文化局及其所屬機關／機構的預算；「文化支出」採政事別分類，可能包含不同機關辦理的文化相關支出。兩者的分類基礎與涵蓋範圍不同，不相互替代。追蹤特定政見時沿用原始承諾所採口徑；比例僅以同年度、同層級、同會計基礎的分子與分母計算。每筆資料另註明是否包含文化局所屬館舍、基金、附屬單位及資本門。

資料狀態

目前 repository 內資料檔採空資料集起始，代表「尚未完成逐筆查核」，不是「候選人沒有文化政見」或「地方政府沒有文化支出」。

更正

更正紀錄包含日期、修正前後內容及理由。可透過 GitHub Issue 提供新來源或提出更正，所有變更保留版本紀錄。
