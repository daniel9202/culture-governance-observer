DATA WORKFLOW

資料更新流程

自動蒐集與公開資料分開。搜尋結果只進待查核清單，必須確認確實是政策主張、補齊欄位後，才加入正式資料。

候選人文化政見

  1. 到 待查核來源 查看每日新增結果。
  2. 排除競選活動、拜會、演出出席及個人經歷。
  3. 確認來源與內容後，把資料填入 正式候選人 CSV。
  4. 填寫最後查核日；有修正時保留更正紀錄。

地方政府預算與支出

  1. 開啟 地方政府財政 CSV。
  2. 分別填入文化預算、文化實際支出、總預算與總支出；金額一律使用新臺幣元。
  3. 預算與決算的來源、年度及機關範圍必須分別註明。
  4. 提交後系統會計算比例、驗證欄位並自動部署。

提交與驗證

在 GitHub 編輯器按「Commit changes」即可。系統會驗證日期、網址、金額與必要欄位；驗證失敗時不會更新公開網站。完整欄位說明請見 repository 的 docs/manual-update.md。
