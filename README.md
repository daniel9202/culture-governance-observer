# 文化治理觀察站｜2026 台灣地方選舉

公開追蹤候選人文化政見，並整理地方政府文化預算、實際支出與重點施政。

## 原則

- 政見與競選活動、個人經歷分開。
- 每筆候選人資料保留來源、發布日、最後查核日與更正紀錄。
- 預算與決算分開，並註明統計口徑。
- 未完成查核的資料不先行發布。

## 更新資料

編輯 `data/candidates.json` 或 `data/governments.json`，依 `data/schema.md` 欄位填寫。推送至 `main` 後，GitHub Actions 會自動部署 GitHub Pages。

## 本機預覽

在專案目錄執行 `python -m http.server 8000`，再開啟 `http://localhost:8000`。
