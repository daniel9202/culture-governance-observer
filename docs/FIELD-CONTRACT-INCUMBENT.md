# 欄位契約變更（第二份）：現任紀錄的分類與身分

資料端提出，依 `AGENTS.md` 要先經設計端確認。影響 `data/input/candidates.csv` 共 **59 筆、44 人**。

---

## 一、問題

`content_nature` 現在有三個值在處理「現任者的紀錄」：

| 值 | 筆數 |
|---|---|
| `現任議員個人頁內容` | 37 |
| `現任問政／提案` | 13 |
| `現任首長施政` | 9 |

三個問題：

1. **涵蓋不到的身分一律收不進來。** 立法委員任內的政績四個值都不適用——蘇巧慧的公共出借權因此整列刪除。謝龍介、陳亭妃、王美惠、蔡易餘、劉建國、張嘉郡都是現任立委參選縣市長，同樣進不來。魏嘉賢是現任花蓮縣議員參選花蓮縣長，他那筆卻被標成「現任首長施政」。
2. **`現任議員個人頁內容` 其實在講來源，不是性質。** 37 筆裡有 30 筆來自議會官網（`hsinchu-cc.gov.tw`、`tncc.gov.tw`、`mtcc.gov.tw` 等），而 `source_type` 欄本來就在記這件事。
3. **前台顯示的是分類名稱，不是讀者關心的身分。** 現在 `fulfillment.js` 把 `content_nature` 直接印成標籤，讀者看到「現任議員個人頁內容」，但真正有意義的是「現任花蓮縣議員」。

---

## 二、變更內容

### 1. `content_nature` 三值合併為 `現任公職政績`

```
現任議員個人頁內容  ┐
現任問政／提案      ├─→  現任公職政績
現任首長施政        ┘
```

**這個值只在後台使用，前台不顯示。** 它回答的是「這是什麼性質的紀錄」——現任公職者任內的作為，與「本屆競選政見」相對。

`本屆競選政見` 不變。

### 2. 新增 `current_office`（現職）

記錄這個人**現在的公職身分**，前台拿它當標籤。命名與 `pledge_fulfillment.csv` 的同名欄位一致。

| 情況 | 值 | 現有的人 |
|---|---|---|
| 現任縣市長 | `現任臺北市長` | 蔣萬安、鍾東錦、周春米、謝國樑、高虹安 |
| 現任縣轄市長 | `現任屏東市長`、`現任宜蘭市長` | 周佳琪、陳美玲 |
| 現任縣市議員 | `現任花蓮縣議員` | 魏嘉賢及其餘 36 位議員 |
| 立法委員 | `立法委員` | 蘇巧慧等六位縣市長候選人 |
| 已卸任 | `前花蓮市長` | （目前無人，魏嘉賢改列現任花蓮縣議員）|

`content_nature` 為 `現任公職政績` 時必填，其餘情況選填。

### 3. 「個人頁主張」與「實際質詢提案」的區別改由 `source_type` 承擔

`AGENTS.md` 規定這兩者要分開標示，理由是個人頁上的主張不等於已正式提案或質詢。合併後這個區別移到 `source_type`，那裡已經有對應的值：

```
議會官方網站      9 筆
政府質詢紀錄      1 筆
議會質詢報導      1 筆
新聞報導、新聞／公開網頁、候選人原文⋯
```

不夠用再補值，但不要再放回 `content_nature`。

## 三、前台要怎麼改（請設計端確認）

1. **標籤改讀 `current_office`**。`fulfillment.js` 的 `councilCard` 現在是
   `<span class="tag">${escapeHtml(record.content_nature)}</span>`，
   改成顯示 `current_office`。讀者看到的是「現任花蓮縣議員」而不是「現任議員個人頁內容」。
2. **分頁怎麼分**。現在是首長／議員兩個分頁，依 `office` 判定。合併後建議改依 `current_office` 分：首長（縣市長、縣轄市長）、民意代表（縣市議員、立法委員）。
3. **要不要顯示資料來源性質**。如果要讓讀者分辨「這是他個人頁的主張」還是「這是實際質詢紀錄」，改讀 `source_type`。
4. `推定現任議員` 的標籤與「並非議會官方認證」說明照舊保留，那是 `proposer_role` 欄，不受這次變更影響。

## 五、順帶要處理的既有問題

- **名冊的 `incumbent` 欄只標了 8 位縣市長**，議員與縣轄市長全是空白。所以現任花蓮市長魏嘉彥（正在爭取連任）在名冊上看不出是現任，30 筆議員紀錄也只能用「推定現任議員」。補齊的話那些推定可以變成確認，但要逐縣市查證。
- **魏嘉賢另外兩筆**標「本屆競選政見」（美崙山與四八高地、豐年節原民主體性），與這次改列的那筆是同類型的公開呼籲，歸類可能要一併重新判定。
